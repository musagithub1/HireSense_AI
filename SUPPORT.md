# Support

## Questions and setup help

Search the README, deployment guide, Supabase guide, and existing GitHub issues
before opening a new issue.

When asking for help, include:

- Operating system and Python version
- Browser and version for voice or camera issues
- The command you ran
- The complete error message with secrets removed
- Whether Supabase, Google sign-in, and OpenRouter are enabled
- A minimal reproduction

Do not include API keys, OAuth secrets, resumes, candidate data, database
tokens, or private URLs.

## Bugs

Use the bug report template. Security vulnerabilities must follow
`SECURITY.md` and must not be reported publicly.

## Feature requests

Use the feature request template and explain the candidate benefit, privacy
impact, accessibility impact, and how success could be tested.
